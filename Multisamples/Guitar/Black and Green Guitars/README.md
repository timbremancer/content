# Black and Green Guitars

This source collection is represented in the Forge Content Store by two
independently installable instruments:

- **Green Guitar** — `Programs/01-green_keyswitch.sfz`
- **Black Guitar** — `Programs/02-black_keyswitch.sfz`

Nested SFZ modules and referenced samples are dependencies inside each
`.timbrelibrary`; they are not public Library entries.
